# mmd_massotherapie
Site vitrine Angular pour MMD Massothérapie, entreprise de massage sportif à Rennes.
Le site présente l'activité, les prestations proposées et permet aux visiteurs de prendre rendez-vous directement en appelant l'entreprise via un simple clic.

## Objectif

Version actuelle : une page d'accueil unique présentant l'activité de l'entreprise.
Le projet est amené à évoluer avec de nouvelles fonctionnalités (galerie, avis clients, prise de rendez-vous en ligne, etc.).

## À propos de l'activité

**MMD Massothérapie** propose des prestations de massage sportif :
- Préparation à l'effort
- Relaxation musculaire
- Récupération sportive
- Cupping thérapie
- Amma assis
